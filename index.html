kis-backup개인용 서버 백업

소유자가 직접 관리하는 백업 도구

서버 파일을 본인의
구글 드라이브에 백업합니다.

kis-backup은 소유자가 선택한 서버 파일을 본인의 구글 드라이브로 복사하고, 전송된 파일의 내용을 비교·검증하는 개인용 도구입니다.

파일 전송은 rclone(파일 전송 도구)에서 실행합니다. 이 웹페이지는 앱의 용도와 데이터 처리 방식을 설명하는 안내 페이지입니다.

선택한 파일 복사

소유자가 지정한 서버 파일과 폴더를 본인의 드라이브로 전송합니다.

전송 내용 검증

파일 수, 크기와 검증값을 비교해 백업 사본을 확인합니다.

소유자가 직접 관리

백업 대상, 실행 시점과 보관·삭제 시점을 소유자가 결정합니다.

요청하는 접근 권한

구글 드라이브의 파일을 조회·생성·수정·삭제할 수 있는 권한을 요청합니다. 현재 사용 목적은 소유자가 지정한 파일의 백업 복사와 내용 검증입니다.

구글 로그인과 접근 승인은 구글의 인증 화면에서 진행합니다. 이 안내 페이지에서는 로그인 정보나 백업 파일을 입력받지 않습니다.

파일과 인증 정보의 보관

백업 원본은 소유자가 운영하는 서버에, 전송된 사본은 소유자의 구글 드라이브에 보관됩니다. 연결을 유지하는 인증 정보는 접근 권한을 제한한 서버 설정 파일에 저장합니다.

처리하는 정보, 보관 방식과 연결 철회 방법은 개인정보처리방침에서 확인할 수 있습니다.
