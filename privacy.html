개인정보처리방침

이 방침은 lgya072가 운영하는 개인용 서버 백업 도구 kis-backup과 이 안내 페이지의 데이터 처리에 적용됩니다.

1. 처리하는 정보

  • 소유자가 백업 대상으로 선택한 파일의 내용
  • 파일과 폴더의 이름, 경로, 크기, 수정 시각 및 내용 검증값
  • 연결 계정 확인에 필요한 구글 드라이브 계정 정보
  • 구글 드라이브 연결을 유지하는 접근 인증 정보와 갱신 인증 정보
  • 파일 전송·검증 결과와 오류 등 백업 작업 기록

구글 계정 비밀번호는 이 백업 도구에서 수집하지 않습니다.

2. 사용 목적

처리한 정보는 소유자가 지정한 파일의 백업, 전송 결과 확인, 드라이브 연결 유지와 백업 오류 확인에 사용합니다. 이 도구를 통해 받은 구글 사용자 정보를 판매하거나, 광고 프로파일링 또는 범용 인공지능 모델 학습 목적으로 사용·제공하지 않습니다.

3. 저장과 전송

백업 원본은 소유자가 운영하는 서버에 있으며, 백업 사본은 소유자가 접근을 허용한 본인의 구글 드라이브에 저장됩니다. 인증 정보는 접근 권한을 제한한 서버 설정 파일에 저장하고, 전송·검증 기록은 운영 서버에 보관합니다.

서버와 구글 드라이브 사이의 파일 전송은 암호화된 통신으로 이루어집니다. 백업 파일과 인증 정보를 이 공개 안내 페이지나 안내 저장소에 저장하지 않습니다.

4. 외부 서비스 및 안내 페이지

백업 사본은 사용자가 선택한 구글 드라이브로 전송됩니다. 이 안내 페이지는 GitHub Pages(깃허브 웹 호스팅)에서 제공하며, 별도의 방문 분석·광고·추적 기능을 두지 않았습니다.

깃허브는 호스팅 서비스의 보안을 위해 방문자의 IP(인터넷 주소)를 기록·보관합니다. 자세한 내용은 깃허브 개인정보처리방침에서 확인할 수 있습니다.

5. 보관과 삭제

백업 사본과 서버 기록의 보관·삭제 시점은 소유자가 결정합니다. 백업 파일은 소유자의 구글 드라이브에서 직접 관리하거나 삭제할 수 있습니다. 서버에 저장한 인증 정보와 기록도 소유자가 관리합니다.

6. 접근 권한 철회

구글 계정의 연결된 앱 관리 화면에서 kis-backup의 접근 권한을 철회할 수 있습니다. 연결 권한 철회와 이미 업로드한 백업 파일의 삭제는 별개이며, 권한 철회가 기존 백업 사본을 자동으로 삭제하지는 않습니다.

7. 문의 및 방침 변경

앱 운영자와 데이터 처리 담당자는 lgya072입니다. 문의 및 정정 요청은 안내 저장소의 문의 게시판으로 전달할 수 있습니다. 데이터 처리 방식이 달라지면 이 페이지의 내용과 최종 수정일을 갱신합니다.

이용 안내

kis-backup은 소유자가 접근 권한을 가진 서버와 구글 드라이브 사이에서 사용하는 개인용 백업 도구입니다. 이 안내 페이지에서는 서비스 가입, 파일 제출 또는 결제를 받지 않습니다. 실제 백업의 대상과 보관 방식은 소유자가 관리합니다.

구글 드라이브와 깃허브 호스팅의 이용에는 각 제공자의 이용 조건 및 개인정보처리방침이 적용됩니다.
